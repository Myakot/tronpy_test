# Tron Address Info Microservice

Этот проект представляет собой микросервис, который предоставляет информацию о заданном адресе в сети Tron. Микросервис реализован с использованием FastAPI и SQLAlchemy.

## Установка


```bash
git clone https://github.com/Myakot/tronpy_test
cd tronpy_test
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

## Запуск микросервиса

Для запуска микросервиса используйте следующую команду:

```bash
uvicorn app.main:app --reload
```
Микросервис будет доступен по адресу http://127.0.0.1:8000.

## Эндпоинты
#### Получение информации по адресу
```
POST /address/
```
#### Тело запроса:
```json
{
  "address": "TXYZ1234567890123456789012345678901"
}
```
#### Ответ:
```json
{
  "bandwidth": 1000,
  "energy": 200,
  "balance": 100.0,
  "address": "TXYZ1234567890123456789012345678901"
}
```
#### Получение списка последних записей
```
GET /logs/
```
#### Параметры запроса:

    last_seen_id (опционально): ID последней записи для пагинации.
    limit (опционально): Количество записей для возврата (по умолчанию 10).

#### Ответ:

```json
[
  {
    "id": 1,
    "address": "TXYZ1234567890123456789012345678901"
  },
  ...
]
```
## Тестирование
Для запуска тестов используйте следующую команду:
```bash
pytest
```
